AquaTick Android

개인정보 처리방침

English한국어

시행일: 2026년 10월 6일. 운영자: Sparkish. 문의: alarmcrew.support@gmail.com.

이 방침은 AquaTick Android 앱과 Wear OS 동반 앱(패키지 com.benghak.aquatick)에 적용됩니다. iPhone·Apple Watch 앱에는 별도의 iOS 개인정보 처리방침이 적용됩니다. AquaTick은 개인 수분 기록 앱이며 의료 서비스가 아닙니다.

기기에 저장하는 기록

계정을 만들지 않아도 물을 마신 기록을 남길 수 있습니다. 수분량, 날짜·시각, 목표, 알림, 컵 프리셋, 선택한 사진과 화면 설정은 Android 앱의 전용 저장소에 보관합니다. 사진은 Android 사진 선택기로 가져와 기기에서 처리합니다. 컵 사진 원본은 AquaTick 클라우드 백업으로 보내지 않으며 Android 자동 앱 데이터 백업은 사용하지 않습니다.

위젯과 진행률 알림은 설정에 따라 오늘의 진행량을 표시합니다. 홈 화면이나 잠금 화면을 볼 수 있는 사람이 이 정보를 볼 수 있습니다. JSON 백업을 내보내면 Android 파일 선택기로 별도 파일이 저장되며, 파일의 보관·공유는 사용자가 관리합니다.

사진의 피사체 분리 기능은 기기에서 Google ML Kit을 사용합니다. ML Kit은 입력 사진과 분리 결과를 Google로 보내지 않습니다. SDK는 모델·호환성 업데이트를 받기 위해 Google에 연결하거나 API 성능·사용 지표를 전송할 수 있습니다. ML Kit 개인정보 안내를 참고하세요.

선택적 Google 로그인과 클라우드 백업

설치한 버전에서 Android 클라우드 동기화를 제공하고 사용자가 이를 켜면 Firebase Authentication이 Google 로그인, 계정 이메일과 Firebase 사용자 식별자를 처리합니다. 식별자는 계정별 기록을 구분하는 데, 이메일은 계정 문의에 사용합니다. Google Drive 접근 권한은 요청하지 않습니다. 동기화에는 유효한 Android Pro 이용권이 필요하지만 기존 클라우드 계정을 삭제하기 위해 Pro를 구매할 필요는 없습니다.

클라우드 백업은 선택한 계정의 수분 기록, 양, 날짜·시각, 시간대, 기록 출처, 컵·음료 메타데이터, 취소 상태와 동기화 정보를 Firebase Firestore로 전송합니다. Health Connect도 켠 경우 거기서 가져온 기록이 포함될 수 있습니다. 기존 로컬 기록을 클라우드 계정으로 옮기기로 선택하면 그 기록도 포함됩니다. 컵 사진 파일, 목표, 알림 설정과 컵 프리셋은 이 백업 범위에 포함되지 않습니다. Android 클라우드는 iOS와 기록을 주고받지 않습니다.

Firestore 접근 권한은 인증된 계정과 서버가 확인한 Android 구독 상태를 기준으로 판단합니다. Firebase App Check와 Play Integrity는 서비스를 보호하기 위해 앱·기기 무결성 확인 정보를 처리할 수 있습니다. 클라우드 제공 여부는 설치한 버전과 서비스 설정에 따라 달라집니다.

Health Connect와 Wear OS

Health Connect는 선택 기능입니다. 사용자가 기능을 켜고 Android의 수분 기록 읽기·쓰기 권한을 허용하면 오늘의 수분 기록을 앱으로 가져오고 AquaTick 기록을 Health Connect에 씁니다. AquaTick 기록을 취소하면 앱이 쓴 대응 Health Connect 기록을 삭제할 수 있습니다. 다른 건강 데이터 종류의 권한은 요청하지 않으며 Health Connect 데이터를 광고, 판매, 신용·고용·보험 판단에 사용하지 않습니다.

Android Health Connect 설정에서 권한을 철회하고 기록을 관리할 수 있습니다. 권한 철회, 앱 제거, 클라우드 계정 삭제만으로 이미 Health Connect에 저장한 기록이나 내보낸 백업의 사본이 모두 삭제되지는 않습니다.

연결된 Wear OS 앱에는 오늘의 진행량, 빠른 기록·취소 명령, 컵 정보와 사진 썸네일을 Google Play services Data Layer로 전달합니다. 연결 상태에 따라 Bluetooth 또는 Google 중계 서비스를 사용합니다. Watch에 캐시가 남을 수 있으므로 Watch 앱 데이터는 별도로 관리하세요. Google Data Layer 설명을 참고할 수 있습니다.

구매와 광고

결제는 Google Play가 처리합니다. RevenueCat은 Pro 이용과 구매 복원을 위해 앱 고객 식별자, 구매·구독 정보와 기기·앱 정보를 처리합니다. AquaTick은 결제 카드 번호를 받지 않습니다. Google Play 구독과 Android Pro는 iOS 구매와 별개입니다. Google Play와 RevenueCat은 자체 정책과 법적 의무에 따라 거래 정보를 보관할 수 있습니다.

무료 이용 시 Google Mobile Ads 배너와 고양이 스킨을 받기 위해 사용자가 선택한 보상 광고가 표시될 수 있습니다. UMP가 해당 지역의 광고 선택을 처리하며 앱은 SDK의 광고 요청 허용 상태를 따릅니다. Google 광고 SDK는 광고, 부정 이용 방지와 측정을 위해 IP 기반 대략적 위치, 기기·광고 식별자, 앱 상호작용과 진단 정보를 처리할 수 있습니다. 유효한 Android Pro 이용권은 앱 내 광고를 제거합니다. 광고 데이터는 수분 기록과 별개이며 건강 기록, 컵 사진과 계정 이메일을 광고 타기팅 필드로 보내지 않습니다. Google 광고 SDK 데이터 설명과 Google 개인정보처리방침을 참고하세요.

제품 분석과 오류 진단

배포 버전은 앱 동작을 이해하고 제품을 개선하기 위해 Firebase Analytics와 Amplitude를 사용합니다. 커스텀 이벤트에는 동작, 화면 맥락, 결과와 제한된 범주형 설정을 담습니다. 컵 생성에 성공하면 설정한 컵 용량(mL), 용량 라벨과 음료 종류를 포함합니다. 이 값은 실제 마신 양이 아닙니다. 프로필의 범주형 값 14개는 구독, 온보딩, 알림, 클라우드, 단위와 컵 개수 구간을 설명합니다. 실제 마신 양, 목표량, 수분 기록 날짜, 직접 지은 컵 이름, 사진, 검색어, 이메일, Firebase 계정 ID와 RevenueCat 구매 ID는 커스텀 분석 이벤트·프로필에 넣지 않습니다.

이 Android 설치에 임의로 생성해 전용 저장소에 보관한 식별자를 두 분석 서비스에 사용합니다. Amplitude는 별도의 임의 기기 식별자도 사용합니다. Google 계정이나 건강 기록에서 만든 값이 아니며 앱 데이터 삭제나 앱 제거 후 바뀔 수 있습니다. 활성화된 Amplitude 사용자 식별자와 Firebase 앱 인스턴스 식별자는 구매 분석을 위해 RevenueCat에도 전달할 수 있습니다. 각 SDK는 앱·기기·운영체제·언어, 상호작용 시각과 세션 등 기술 정보를 처리할 수 있습니다.

Amplitude의 자동 수집은 세션으로 제한합니다. Amplitude에서는 광고 ID, App Set ID, 통신사, 좌표, IP 기반 위치 수집과 화면·요소·네트워크 자동 추적, Session Replay, SDK 진단 전송을 사용하지 않습니다. Amplitude 프로젝트는 미국 지역을 사용합니다. Firebase Analytics는 자체 기술 정보를 자동 수집할 수 있으며 이 Amplitude 제한이 다른 모든 SDK에도 적용된다는 뜻은 아닙니다. Crashlytics는 분석 수집과 별도로 오류 추적, 설치 식별자와 기기·앱 정보를 처리해 장애를 진단합니다. Firebase 개인정보 안내와 Amplitude Privacy Notice를 참고하세요.

보관, 삭제와 사용자 선택

로컬 데이터는 앱이나 Android 앱 데이터 관리 기능으로 삭제할 때까지 남습니다. 클라우드 기록과 취소 메타데이터는 계정이 유지되는 동안 보관하며 계정 삭제 또는 삭제 요청으로 제거합니다. 수분 기록 하나를 취소해도 기기 간 동기화에 필요한 취소 정보는 남을 수 있습니다.

앱의 클라우드 계정 삭제 기능 또는 계정 및 데이터 삭제 페이지를 이용하세요. 본인 확인 후 서버 삭제는 Firebase Authentication 사용자, Firestore 프로필, 수분 기록과 계정별 동기화·RevenueCat 연결 정보를 제거합니다. 앱에서 삭제하면 현재 휴대폰의 해당 계정 캐시와 동기화 대기 작업도 제거합니다. 외부 요청으로 모든 휴대폰·Watch·내보낸 파일·Health Connect 기록·구독을 원격 삭제할 수는 없습니다.

오래된 작업이 삭제된 계정을 다시 만들지 못하도록 서버 전용 삭제 표식에 Firebase 식별자, 삭제·만료 시각과 차단 동기화 세대를 보관합니다. 이메일, 수분 기록과 RevenueCat 고객 식별자는 포함하지 않습니다. 설정된 보관 기간은 90일이며 일일 정리 후 통상 90~91일에 제거합니다. 인증 계정이나 잔여 데이터 삭제가 실패하면 삭제와 확인된 정리가 성공할 때까지 표식을 유지합니다. 외부 서비스의 백업·보안 로그·분석·구매 정보는 각 제공자의 정책을 따르므로 클라우드 계정 삭제가 별도 정보의 즉시 삭제를 뜻하지는 않습니다.

개인정보를 판매하지 않습니다. 열람, 정정이나 삭제는 지원 이메일로 요청할 수 있으며 계정 데이터를 공개하거나 지우기 전에 본인 여부를 확인합니다. 비밀번호, 로그인 토큰과 결제 인증 정보를 보내지 마세요. 건강 기록은 필요성이 확인된 지원 요청에서 별도로 합의한 경우에만 제공하세요. 지원은 문의에 답하기 위해 이메일과 사용자가 자발적으로 제공한 내용을 처리합니다. 서비스 제공자는 사용자의 국가 밖에서 정보를 처리할 수 있습니다. 인터넷 서비스는 전송을 암호화하지만 완전한 보안을 보장할 수는 없습니다.

변경과 문의

Android 앱의 데이터 처리 방식이 바뀌면 이 방침과 시행일을 갱신합니다. 개인정보 문의·요청은 alarmcrew.support@gmail.com으로 보내세요. Android 이용약관과 Android 고객지원도 확인할 수 있습니다.
