Verified flow

  1. Grant access Request only hydration read and write through the Android system screen. The privacy link opens the app explanation and published policy link.
  2. Read A 350mL synthetic record written by the official Health Connect Toolbox is imported into AquaTick. Repeated reconciliation does not duplicate it.
  3. Write and undo Logging a 200mL cup changes the app total to 550mL and writes an AquaTick-owned provider record. Undo returns to 350mL and deletes only that app record.
  4. Turn syncing off A new local 200mL record remains available while syncing is off; no new provider record is written.
  5. Revoke access The SDK schedules self-revocation for process termination. A fresh process confirms both permissions are absent and can still log locally, reaching 750mL.

Environment and scope

AquaTick 1.1.6 (97), Debug · com.benghak.aquatick · Android 16 / API 36 · 1080 × 2424 · 2026-10-06. Health Connect SDK 1.1.0, official Toolbox 2.3.5.

Only synthetic data is used. Cloud sync and app analytics collection are disabled in this verification build. This video does not prove production purchases, cloud recovery, paired Wear behavior, the final signed AAB, or Google Play approval.
