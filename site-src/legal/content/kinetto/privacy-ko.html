KINETTO가 저장하는 정보

KINETTO는 익명 서버 계정을 사용합니다. 외부 로그인은 없습니다. 기기 세션 토큰은 이 기기의 키체인에 저장됩니다. 서비스는 러닝 기록을 보관하고 검증하기 위해 계정 설정, 비공개 러닝 요약, 그리고 사용자가 업로드한 비공개 GPS 경로 데이터를 저장합니다.

선택 입력한 개인 신체 정보는 이 기기에만 남습니다. 다른 사용자는 이름, 기기 식별 정보, 정확한 경로·위치·활동 시각, 페이스, 심박수, 신체 정보를 볼 수 없습니다.

Apple 건강

Apple 건강 접근은 선택 사항입니다. 사용자가 앱을 보고 있는 상태에서 직접 선택하면 KINETTO가 접근 가능한 러닝 운동 목록을 보여 줍니다. 선택한 운동의 날짜, 시간, 거리와 가능한 경우 운동 에너지 요약만 저장하고 업로드합니다. 건강 앱의 경로, 심박수, 체중은 가져오지 않습니다. 가져온 러닝은 다른 러닝과 같은 선택형 개인정보 보호 지연과 일반화된 게임 활동 규칙을 따릅니다. 완료한 KINETTO GPS 러닝을 Apple 건강에 내보내도록 선택할 수도 있습니다. 건강 앱 접근 없이도 러닝을 기록할 수 있습니다.

Firebase 알림, 분석, 오류 보고

KINETTO는 Google이 제공하는 Firebase 서비스를 사용합니다. iOS에서 기기 알림을 켜면 Firebase Cloud Messaging이 알림 전달에 필요한 알림 등록 토큰과 기술적 기기·앱 정보를 처리할 수 있습니다. KINETTO는 알림 전달 목적에서만 토큰을 익명 서버 계정에 연결하며, 이름을 Firebase에 보내거나 Analytics에서 이용하지 않습니다.

사용 분석과 오류 보고는 선택 사항이며 기본적으로 꺼져 있습니다. 앱에서 사용 분석 및 오류 보고(버전 firebase-v1)에 명시 동의한 뒤에만 Firebase Analytics를 켜고 Firebase Crashlytics가 기기에 보관된 오류 보고를 전송하도록 허용합니다. 켜진 경우 Firebase는 Firebase 설치·오류 식별자, 앱·기기·운영체제 정보 및 앱 충돌 시 시각, 진단 상태, 스택 추적을 처리할 수 있습니다. 동의한 Analytics의 경우 Firebase는 IP 주소에서 추정한 대략적인 지역도 처리할 수 있습니다. Analytics와 Crashlytics가 모두 켜진 경우 Firebase는 최근 앱 동작에 관한 SDK 관리 Analytics breadcrumb를 오류 보고에 첨부할 수 있습니다. KINETTO는 Analytics 이벤트나 Crashlytics 사용자 정의 값으로 정확한 위치, 경로, 건강 데이터, 러닝 상세, 자유 입력 글 또는 KINETTO 계정·사용자 식별자를 보내지 않습니다. 광고 식별자 수집과 자동 화면 보고도 켜지 않습니다.

설정에서 동의를 철회할 수 있습니다. 앱은 Analytics를 중단하고 이후 Crashlytics 오류 보고 전송을 막으며, 전송하지 않은 오류 보고를 삭제하고 Firebase Analytics 데이터를 초기화합니다. 이 선택은 기기 알림 전달을 바꾸지 않습니다. 기기 알림을 끄면 로컬에 캐시된 알림 토큰을 지우고 Firebase Messaging 토큰을 제거하지만, 별도로 동의한 Analytics가 계속 동작할 수 있도록 Firebase 설치 식별자는 초기화하지 않습니다. 계정을 삭제하거나 익명 계정을 교체하면 KINETTO가 보관한 알림 등록 정보를 지우고 Firebase Messaging 데이터와 설치 상태를 제거합니다. 이미 Firebase로 전송된 데이터의 처리는 Google의 Firebase 문서와 정책을 따릅니다.

Firebase SDK 구성요소는 Firebase 서비스 운영과 도입 현황을 위해 앱·기기·운영체제·개발 플랫폼에 관한 기술적 SDK 사용자 에이전트 정보를 보낼 수 있습니다. Firebase는 해당 사용자 에이전트를 사용자 또는 기기 식별자와 연결하지 않는다고 설명합니다.

익명 참여

익명 참여는 비공개 러닝 기록과 별도의 선택 사항입니다. 켜면 KINETTO는 개인정보 보호 지연 후 일반화한 활동만 공개할 수 있습니다. 끄면 이후 러닝은 비공개로 유지되고 새 소셜 참여가 중지됩니다.

사용자 선택권

앱에서 설정과 참여 상태를 바꾸고, 계정 데이터를 내보내거나 삭제를 요청할 수 있습니다. 삭제는 재개 가능한 절차로 비공개 계정 데이터를 제거합니다. 안전, 무결성, 분쟁, 부정 사용 방지 또는 법적 의무에 필요한 기록은 적용 정책에 따라 가명화하여 보관될 수 있습니다.

공유와 보안

비공개 경로는 소유자만 볼 수 있습니다. 서비스 운영에는 최소화된 가명 데이터를 사용하며, 세션 자격 증명과 비공개 데이터는 플랫폼과 서비스 보안 제어로 보호합니다.
