알람크루(AlarmCrew)는 8자리 초대 코드로 같은 크루에 참여하고 기상 현황을 공유하는 iPhone·iPad 알람 앱이에요. 친구를 서로 팔로우하는 것과 크루에 참여하는 것은 별개이므로, 함께 쓸 크루의 코드를 직접 공유하고 입력해 주세요.

초대하는 사람: 코드 공유하기

  1. 함께 사용할 크루의 상세 화면을 여세요.
  2. ‘초대 코드 공유’ 항목에서 8자리 코드를 확인하세요.
  3. 해당 항목을 눌러 코드를 복사하거나 공유하고, 함께 참여할 사람에게 전달하세요.

코드가 아직 표시되지 않으면 인터넷 연결과 동기화 상태를 확인하세요. 화면에 안내된 동기화가 끝난 뒤 공유해 주세요.

초대받은 사람: 크루 참여하기

  1. iOS 26.0 이상의 iPhone·iPad에서 알람크루를 열고 로그인하세요.
  2. 알람 목록의 크루 참여 기능을 열고 받은 8자리 코드를 입력하세요.
  3. 참여를 완료한 뒤 크루 상세에서 자신의 알람 상태와 참여자 목록을 확인하세요.

코드를 찾을 수 없다는 안내가 나오면 전달받은 코드를 다시 확인하세요. 네트워크 오류가 나면 인터넷 연결을 확인한 뒤 다시 시도해 주세요.

기상 현황은 어떻게 공유되나요?

알람을 해제하면 크루에 기상 완료가 전해지고, 같은 크루에서 기상 완료·대기 상태와 반응 시간을 볼 수 있어요. 로그인과 크루 현황 동기화에는 인터넷 연결이 필요합니다.

기기에 등록된 알람은 기기에서 실행되지만, 전원이 꺼져 있으면 울리지 않아요. 알람 권한과 음량, 배터리 설정을 확인하고 자신의 알람 상태를 살펴보세요. 로그아웃하면 해당 기기의 예약 알람이 해제됩니다. 알람은 각 기기의 현지 시각을 기준으로 해요.

친구가 되면 자동으로 참여되나요?

서로 팔로우해 친구가 되어도 크루에 자동으로 가입되지는 않아요. 원하는 크루의 초대 코드를 입력해 참여해야 합니다. 친구 추가와 크루 가입의 차이에서 자세히 확인하세요.

지원 기기와 개인정보

iOS 앱은 App Store에서 다운로드할 수 있고 Android는 출시 준비 중입니다. 현재 Android 다운로드나 확정된 출시일은 제공하지 않아요. 앱에는 광고가 포함되며, 계정·기상 기록과 광고·진단 정보에 대한 설명은 개인정보 처리방침에 있습니다.

참여나 동기화 문제가 계속되면 고객지원에 기기·OS 버전과 표시된 오류를 알려 주세요. 초대 코드는 공개 게시판에 올리지 말고 참여할 사람에게 직접 전달하세요.
