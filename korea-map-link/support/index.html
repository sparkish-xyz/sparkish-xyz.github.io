Common questions

English search returns no results

Try a shorter name, add a neighborhood (e.g. “Hongdae cafe”), search “London Bagel Anguk” or “Olive Young Hongdae”, paste a Google Maps link from Instagram, or filter by region when many branches exist. Built-in aliases expand popular tourist names to Korean search terms.

Naver or Kakao Map does not open

Install Naver Map or Kakao Map from the App Store. If already installed, tap again or use the web fallback from the error message. Register your device language in the map app when possible.

Google Maps link is rejected

Only supported Google Maps URL hosts are accepted. Copy the link from the Share menu in Google Maps, not a generic web search result.

Location-based search is wrong

Enable Location for Korea Map Link in Settings → Privacy → Location. You can also pick a region manually in the App.

Ads or privacy choices

The taxi card screen has no ads. Other screens may show ads after consent. Open Settings in the App for ad privacy options when available.

Siri Shortcuts

Use Shortcuts to search a place, open your last result in Naver Map, or show the taxi card for the last place.
