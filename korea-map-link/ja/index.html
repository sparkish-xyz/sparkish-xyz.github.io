Googleマップに保存した？リンクを貼り付けるだけ。

Googleマップは探すのに便利ですが、韓国ではNaverとKakaoで行きます。Korea Map Linkが韓国語の名称と住所を見つけ、NaverまたはKakaoを開き、タクシー運転手に見せる広告なしカードを表示—アプリ間のコピペ探しはもう不要です。

使い方

  1. 入力 iOS共有シートでGoogleマップから共有するか、Airbnb・ホテルの住所、Instagramで見つけた店、英語の店名を貼り付けます。
  2. 確認 アプリ間で韓国語名を探す必要はありません—英語入力やリンクをNaver・Kakao候補とマッチングします。
  3. 開く 道案内はNaver・Kakaoで、運転手には一目で読める広告なしタクシーカードを表示します。

よくある質問

Googleマップは韓国で使えますか？

Googleマップは計画には便利ですが、韓国では徒歩・車のリアルタイム案内が制限されています。現地ではNaver・Kakaoが主流です。本アプリはGoogleで保存した場所を現地の地図アプリにつなぎます。

Googleマップから共有できますか？

はい。iOS共有シートで Korea Map Link を選ぶと、共有した場所を韓国語 handoff チケットに即座に変換します。

アカウントは必要ですか？

登録不要です。最近のリンクと保存場所は Home・Saved・Taxi タブで端末に保存されます。

Airbnbやホテルの住所を貼り付けられますか？

はい。予約確認の住所やGoogleマップリンクを貼り付けてください。Korea Map Linkが韓国語情報を解決し、Naver・Kakaoを開いてタクシーカードを表示できます。

アプリは無料ですか？

検索・一覧に広告ありの無料アプリです。タクシー画面は広告なしです。
